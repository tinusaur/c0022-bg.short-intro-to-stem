# Кратък увод в STEM (наръчник)

Примерен наръчник за преподаване на ученическия курс **Кратък увод в STEM** (издание `C0102-BG`). Логически идентификатор **`C0202`**. Английските слайдове са **`C0602`**.

**Аудитория:** учители, преподаватели в занималня и STEM фасилитатори.

Пътеките за преподаватели са свързани с по една ученическа група: **V21** за начинаещи читатели, **V22** за по-млади читатели. Няма **V23**, докато `C0102` няма по-дълбока ученическа пътека.

Темите са кратки урочни удари (`problem` / `info` / `assignment`) с **`::: helper`** бележки, в същия дух като примера C0042. Въведенията към уроците назовават групата в две-три изречения.
